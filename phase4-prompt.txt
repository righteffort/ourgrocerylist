3. Cloud Function: mutation handler

Single callable Cloud Function that handles all command types
Transaction logic: read current document → compute stable fingerprint of current state → compare to expected fingerprint from client → on match: write and update fingerprint → on mismatch: reject and write conflict notification
For AddItem: no fingerprint check needed (new document)
For DeleteItem: fingerprint check, then delete
For EditItem/CheckItem/UncheckItem: fingerprint check, then update
Conflict notification document structure and write path (lists/{listId}/notifications/{clientId}/pending/{notificationId})
